# Project-Globe

Currently a work-in-progress. The mod is meant to simulate globe logic for Vintage Story's 2D map. 

Going East or West past a map border will land you at the opposite edge of the map as if you were walking around a real globe.

Pole logic is different, as it behaves in the opposite way of what you think. Walking across a Pole edge lands you at half the value of the opposite meridian, this is how a globe really works.
